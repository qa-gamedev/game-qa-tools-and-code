# Game & Desktop QA Automation Tools

Репозиторий содержит инструменты для автоматизации задач тестирования (GUI stress testing, эмуляция пользовательского ввода, проверка устойчивости интерфейса).

## Python Multi-Marker Auto-Clicker

Инструмент с графическим интерфейсом для проведения стресс-тестирования UI, автоматизации последовательностей кликов и проверки устойчивости кликабельных элементов к спам-нажатиям.

### Ключевые возможности:
* **Интерактивные маркеры (Overlay):** Создание подвижных визуальных маркеров на экране с автоматическим прохождением кликов насквозь (Win32 API).
* **Цепочки кликов:** Настройка порядка нажатий, перерасчет номеров при удалении маркеров и возможность задавать мульти-клики (xN) для каждой точки.
* **Гибкие режимы:** Клик по расставленным маркерам или по текущему положению курсора.
* **Контроль выполнения:** Настройка задержки (в секундах), зацикливание (определенное число циклов или бесконечно) и автоотключение по таймеру.
* **Глобальная горячая клавиша:** Быстрый запуск и остановка по клавише `F6` из любого окна.

### Стек технологий:
* **Python 3**
* `pynput` — перехват глобальных клавиш и эмуляция ввода.
* `tkinter` — графический интерфейс и наложение оверлеев.
* `ctypes` (Win32 API) — реализация прозрачности окон маркеров для физических кликов.
