# 🛠️ Python AutoClicker Studio (GUI Testing Utility)

Инструмент с графическим интерфейсом для автоматизации задач тестирования (GUI stress testing, эмуляция пользовательского ввода, проверка устойчивости интерфейса). Программа разработана для автоматизации рутинных проверок в десктопных приложениях и играх.

## 🚀 Ключевые возможности

Программа поддерживает 4 режима работы для разных сценариев тестирования:
* **Режим 1 (Базовый автоклик):** Клик по текущему положению курсора с настраиваемой задержкой.
* **Режим 2 (Маршрут по маркерам):** Создание интерактивных визуальных маркеров (Overlay) поверх окон с автоматическим прохождением кликов по цепочке насквозь (через Win32 API).
* **Режим 3 (Burst / Умножитель кликов):** Эмуляция множественных нажатий за один физический клик пользователя для проверки элементов на спам-нажатия.
* **Режим 4 (Макросы):** Запись и точное воспроизведение цепочки перемещений мыши и кликов для автоматизации повторяющихся тест-кейсов.

## ⚙️ Контроль выполнения
* **Настройка таймингов:** Задание точной задержки между действиями (в секундах).
* **Циклы:** Возможность зацикливания маршрутов и макросов (заданное количество раз или бесконечно).
* **Безопасность:** Встроенный таймер автоотключения и глобальная горячая клавиша `F6` для мгновенной остановки скрипта из любого окна.

## 💻 Стек технологий
* **Python 3**
* **pynput** — перехват глобальных клавиш и эмуляция ввода.
* **tkinter** — разработка графического интерфейса.
* **ctypes (Win32 API)** — реализация прозрачности окон маркеров для физических кликов.

## 📥 Быстрый запуск
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install pynput`
3. Запустите скрипт.
